# Restos vegan à mi-chemin

Restaurants avec des plats vegan entre Bormes-les-Mimosas et Garéoult (Var), avec filtres et flyer à partager.

- `index.html` : la page, sans dépendance à installer
- `flyer-restos-vegan.jpg` : le flyer prêt à envoyer

Les cartes, prix et horaires changent souvent : à vérifier auprès des restaurants.
